Give me 4 better, new designs of what this could look like.
Each one is a separate real image render.

## Always the actual app UI

- Render the app's own components.
- Use its real icons, fonts, colors, and spacing.
- Never draw a mockup from scratch.
- Never invent icons or UI elements the app doesn't have.
- Change only what the design is about.
- The rest of the page looks exactly like the app today.
- Show the whole page, in 16:9.

## If unsure, look first

- Unsure how a page looks? Take a screenshot of that page in the real app before designing.
- Check every render against it.
- A render that doesn't look like the same app is not ready to show.

## How

- If the project has a skill for rendering the real app, follow it. In Cloudroom that is `ui-change-preview`.
- Otherwise run the app or its component stories, and screenshot the real page.
- Revert temporary code when done.
- Clean screenshots only: no red boxes, numbers, or notes on the images.
